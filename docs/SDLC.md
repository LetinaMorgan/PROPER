# Project SDLC: Platform MVP Tracking

## 1. Project Identity
*   **Proposed Name:** **Proper** (Secondary Options: Hearth, Mettle, Standard)
*   **Tagline:** "The Modern Tool for Classic Service."
*   **Status:** Initializing MVP Phase

---

## 2. Technical Stack (The "Workshop")
| Layer | Choice | Rationale |
| :--- | :--- | :--- |
| **Frontend** | React (Vite) + TS | Fast development, PWA support for mobile home-screens. |
| **Backend** | Node.js (Fastify) | High-performance async handling for SMS/Webhooks. |
| **Database** | PostgreSQL | Relational integrity for complex scheduling. |
| **Styling** | Tailwind + CSS Variables | Achieving the "Retro-Calm" aesthetic (Serif fonts + muted tones). |
| **Storage** | Supabase Storage | Handling Pro menu images and marketing video clips. |
| **Payments** | Stripe Connect | Essential for multi-party payout splits. |
| **Messaging** | Twilio SMS | The "shield" against no-shows. |

---

## 3. Development Roadmap (8-Week Sprint)

### Phase 1: Foundation & Identity (Weeks 1-2) 
- [ ] Define Brand Guidelines (Color palette: Cream `#FDFBF7`, Navy `#1A2B3C`).
- [ ] Setup Repository & CI/CD Pipelines.
- [ ] Implement Auth (Pro & Client roles).
- [ ] **Milestone:** Baseline PWA accessible on mobile.

### Phase 2: The "Pro Tool" (Weeks 3-4)
- [ ] Pro Onboarding Wizard (The 3-minute setup).
- [ ] Service Menu Builder (Flat rates vs. "Starting at").
- [ ] Availability Settings (Operating hours & Zip code radius).
- [ ] **Milestone:** Pro can view their own storefront.

### Phase 3: The "Booking Engine" (Weeks 5-6)
- [ ] Client Landing Page (`proper.app/pro-name`).
- [ ] Dynamic Calendar Logic (Google/Apple sync).
- [ ] Location-Aware Buffer System (Initial zone-based implementation).
- [ ] **Milestone:** A client can pick a slot and fill out their info.

### Phase 4: Financial & SMS Shield (Week 7)
- [ ] Stripe Connect Integration (Deposit collection).
- [ ] Twilio Webhook Engine (24h Confirm/Reschedule loop).
- [ ] "On My Way" Dispatch SMS.
- [ ] **Milestone:** End-to-end transaction flow with notifications.

### Phase 5: Marketing & Hook Generation (Week 8)
- [ ] "Content Mode" UI: Pro can upload raw clips.
- [ ] Marketing Hook Templates (Video script generators for IG/TikTok).
- [ ] Beta Testing with 5 Certified Experts.
- [ ] **Milestone:** Platform Live.
